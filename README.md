# jovery - 个人代理规则库

本仓库用于存放个人使用的 Surge/Quantumult X 模块、规则及脚本。

## 目录结构
- `modules/` : 存放 .sgmodule 模块文件
- `rules/` : 存放 .list 分流规则
- `scripts/` : 存放 JavaScript 脚本
